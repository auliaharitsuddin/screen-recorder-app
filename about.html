Penjelasan singkat fitur dan tampilan di aplikasi ini.

Pengaturan

Resolusi

Pilih kualitas gambar rekaman: 1080p (paling tajam), 720p (seimbang), atau 480p (paling ringan).

Kompresi

Mengatur ukuran file hasil rekaman. Semakin tinggi kompresi, file semakin kecil tapi kualitas gambar sedikit menurun.

Audio sistem/tab

Ikut merekam suara yang keluar dari layar atau tab yang dibagikan, misalnya suara video atau musik.

Mikrofon

Ikut merekam suara Anda lewat mikrofon. Akan muncul izin tambahan saat diaktifkan. Jika izin ditolak, rekaman tetap jalan tanpa suara mikrofon.

Tombol kontrol

Mulai Rekam

Memilih layar/window/tab yang mau direkam. Ada hitung mundur 3-2-1 sebelum rekaman benar-benar mulai, supaya sempat bersiap.

Jeda / Lanjutkan

Menghentikan sementara rekaman tanpa memotongnya jadi file terpisah, lalu bisa dilanjutkan kapan saja.

Stop

Mengakhiri rekaman dan menyiapkan hasilnya untuk diputar atau diunduh.

Tampilan saat merekam

Titik merah berkedip & status

Menunjukkan rekaman sedang berjalan atau sedang dijeda.

Timer durasi

Menampilkan lama rekaman berjalan dalam format menit:detik.

Mic aktif

Muncul saat mikrofon berhasil diaktifkan, sebagai tanda suara Anda ikut terekam.

Preview langsung

Menampilkan pratinjau layar yang sedang direkam, untuk memastikan sumber yang dibagikan sudah benar.

Setelah rekaman selesai

Pemutar hasil rekaman

Hasil rekaman bisa langsung diputar di halaman ini untuk dicek sebelum diunduh.

Tombol Download

Menyimpan hasil rekaman sebagai file video ke perangkat Anda.

Ukuran file & durasi

Ringkasan ukuran file dan lama rekaman, untuk cek cepat apakah pengaturan kompresi sudah sesuai kebutuhan.

Privasi

100% lokal

Semua proses rekam terjadi langsung di komputer Anda. Tidak ada rekaman yang dikirim atau diunggah ke internet.
